# 🎸 GuitarStore — E-Commerce Web Application

Веб-приложение интернет-магазина музыкальных инструментов (гитар, аксессуаров и усилителей), разработанное на фреймворке **Django**.

## 🚀 Основной функционал
- **Каталог товаров и категории:** Просмотр гитар, фильтрация и детальные страницы товаров.
- **Регистрация и автозирация:** Возможность создать аккаунт с двойным подтверждением пароля.
- **Корзина покупок:** Добавление товаров, управление количеством (кнопки `+` / `−`), подсчет общей стоимости и позиций.
- **Избранное (Wishlist):** Возможность добавлять любимые гитары в избранное.
- **Отзывы и комментарии:** Авторизованные пользователи могут оставлять отзывы к товарам.
- **Панель администратора:** Управление товарами, категориями и заказами через встроенную админку Django.

## 🛠 Технологии
- **Python 3.12*
- **Django** 
- **SQLite** 
- **Bootstrap 5 / HTML / CSS** 

## 📂 Структура проекта
- `guitar_shop/` - корень проекта содержащий остальные компоненты.
- `guitarshop` - основная папка с настройками проекта (settings.py).
- `guitar_shop/main` - содержит основные страницы templates, компоненты и файлы views, models и т.д.
- `guitar_shop/users` - регистрация, авторизация и выход из аккаунта пользователя.
- `guitar_shop/apps/main/migrations` - выполненные миграции.
